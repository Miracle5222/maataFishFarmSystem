## 🗄️ Database Credentials

**Verify These Match Your Hosting:**

File: `config/db.php`
```php
$host = 'localhost';      // Usually 'localhost'
$user = 'YOUR_DB_USER';   // Database username
$pass = 'YOUR_DB_PASS';   // Database password
$db = 'maata';             // Database name
```

**To Find Your Credentials:**
1. Log into cPanel
2. Databases → MySQL Databases
3. Find your database name and user
4. Update `config/db.php` if different
